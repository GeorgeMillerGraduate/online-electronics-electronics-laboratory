SPICE netlist & analysis
Edit the analysis command or use your own complete netlist. Analogue and digital circuits run as separate experiments in this edition.
In schematic mode, the analysis field sets the generated command. In imported/edited mode, change the analysis directive inside the netlist itself.
Supported analysis: .tran, .op, .dc and .ac. Complex AC output is plotted as magnitude.
Experiment notes & model limits
Digital ICs are functional logic models with X (unknown) and Z (undriven) states. Supply pins must be wired. Propagation delays and analogue electrical ratings are not modelled. The analogue bench uses real ngspice WebAssembly. The Z80 runs a complete instruction core with a fixed computer mapping.
